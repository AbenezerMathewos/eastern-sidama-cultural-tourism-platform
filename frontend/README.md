# Web-Based Community-Led Cultural Tourism Platform

A full-stack MERN web application developed to promote and manage community-led cultural tourism in Eastern Sidama Zone, Ethiopia. The platform connects tourists, local guides, community hosts, and administrators through a centralized digital tourism system.

---

## Features

- User Authentication & Authorization
- Tourist Experience Booking System
- Community Host Management
- Tour Guide Registration & Approval
- Cultural Experience Listings
- Admin Dashboard
- Booking Management
- Role-Based Access Control
- Review & Feedback System
- Responsive User Interface
- Secure REST API

---

## System Users

### Visitor / Tourist
- Browse cultural experiences
- Book experiences
- Manage bookings

### Community Host
- Create and manage experiences
- Upload cultural content
- Manage bookings

### Tour Guide
- Register as guide
- Manage tourism activities
- Assist visitors

### Administrator
- Manage users
- Approve guides and hosts
- Monitor platform activities
