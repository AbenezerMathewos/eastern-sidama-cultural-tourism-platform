# Community-Led Cultural Tourism Platform

## Overview

Community-Led Cultural Tourism Platform is a full-stack web application developed as my final-year Computer Science project at Hawassa University. The platform promotes community-based cultural tourism by connecting local communities in Eastern Sidama with travelers. It enables communities to showcase their cultural heritage, attractions, accommodations, traditional events, and local experiences through a modern web application.

## Features

- User registration and authentication
- Browse cultural tourism destinations
- Explore attractions and local experiences
- Community profile management
- Tourism information management
- Search and filtering
- Personal Wishlist & Saved Experiences (bookmark and manage favorite cultural tours)
- Responsive design
- Admin dashboard for managing tourism content

## Tech Stack

### Frontend
- React
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Purpose

The objective of this project is to promote sustainable, community-led tourism by providing a digital platform where local communities can present their cultural heritage and tourism services to domestic and international visitors.

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/community-led-cultural-tourism.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
