## [1.0.0] - 2026-09-11
### Added
- Initial release of the Eastern Sidama Cultural Tourism Platform
- User authentication with email verification
- Experience/tour browsing and booking system
- Host application and management workflows
- Guide application and management workflows
- Wallet and withdrawal system for hosts
- Admin dashboard with payouts management
- Interactive cultural guides (coffee, cuisine, music, wildlife, etc.)
- Explore map for discovering local experiences
- Messaging system between users
- Review and rating system
- Wishlist functionality
- Notification system
- Dark/light theme support
